# Hytera Website Clone

This project is a clone of the Hytera.com homepage, focusing on the key sections including:

1. Header/Navigation
2. Hero Slider
3. Breadcrumb Navigation
4. "Explore Solutions" Section with 4 cards
5. Footer

## Project Structure

```
Hytera-Clone/
├── index.html            # Main HTML file
├── assets/
│   ├── css/
│   │   └── styles.css    # Main CSS file 
│   ├── js/
│   │   └── main.js       # Main JavaScript file
│   ├── images/           # Image assets
│   └── fonts/            # Font files (if needed)
└── README.md             # Project documentation
```

## Features

- **Responsive Design**: Works on mobile, tablet, and desktop devices
- **Interactive Elements**: Dropdown menus, slider with navigation
- **Modern Design**: Matches Hytera's branding and aesthetic
- **Performance Optimized**: Fast loading and smooth interactions

## Dependencies

- jQuery 3.7.1
- Font Awesome 6.5.1 (for icons)
- Slick Carousel 1.8.1 (for slider)

## Setup and Usage

1. Clone the repository
2. Open `index.html` in your browser to view the site
